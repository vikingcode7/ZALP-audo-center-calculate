ZALP WEB COMMAND CENTER v2.0

1. Bontsd ki a ZIP-et egy új mappába.
2. Dupla kattintás: ZALP_WEB_START_V2.bat
3. Böngésző: http://127.0.0.1:8080
4. A szerver kiírja a helyi hálózati IP-címet.

Újdonságok: mobilbarát felület, hangszóró-adatbázis, több menthető projekt, Audio Designer, Power Station, Ohm-törvény. Az adatok a zalp_web_data/database.json fájlba kerülnek.

Biztonság: nincs bejelentkezés; csak megbízható helyi hálózaton használd. Ne állíts be routeres porttovábbítást. Külső Python-csomag nem szükséges.
